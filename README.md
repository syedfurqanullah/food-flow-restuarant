# 🍽️ FoodFlow — Restaurant Management & Ordering System

FoodFlow is a frontend-based restaurant management and food ordering web application developed as a **team collaboration project under the Bano Qabil training program**.

The project aims to provide a modern, responsive, and user-friendly experience for customers to explore food items and place demo orders, while allowing administrators to manage menu items and orders through an organized dashboard.

## 🎯 Project Objectives

- Build a modern and responsive restaurant website.
- Practice frontend development using HTML, CSS, and JavaScript.
- Implement essential food ordering and restaurant management features.
- Learn Git and GitHub through collaborative development.
- Improve teamwork, code organization, and project management skills.

## ✨ Key Features

### Customer Website
- Modern homepage with restaurant branding.
- Food menu with categories and search functionality.
- Food cards with images, descriptions, and prices.
- Shopping cart with quantity controls.
- Checkout form with basic validation.
- Demo order placement and order confirmation.
- Responsive design for desktop, tablet, and mobile devices.

### Admin Panel
- Dashboard for an overview of restaurant activity.
- Add, edit, and delete food items (CRUD operations).
- Manage customer orders and update order statuses.
- Organized interface for restaurant management.

### Additional Features
- LocalStorage for saving demo data in the browser.
- Reusable UI components and organized source files.
- GitHub branches and pull requests for team collaboration.

> **Note:** This is a frontend demonstration project. Real authentication, online payments, and centralized data management require a secure backend and database.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layouts, and responsive design
- **JavaScript** — Interactive features and application logic
- **LocalStorage** — Browser-based demo data persistence

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code
- Git
- VS Code Live Server extension (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder in VS Code.

3. Install the Live Server extension if it is not already installed.

4. Open `index.html` with Live Server.

5. Explore the customer website and navigate to the admin panel to test the available features.

*Replace `<repository-url>` with your actual GitHub repository URL.*

## 👥 Team Collaboration

This project follows a collaborative GitHub workflow to help team members work on separate features while maintaining code quality.

**Workflow:**

`Create Branch → Develop → Commit → Push → Pull Request → Code Review → Merge`

### Contribution Guidelines

1. Create a separate branch for your assigned feature.
2. Follow the existing folder structure and coding conventions.
3. Write clear commit messages.
4. Test your changes before pushing them.
5. Open a pull request to merge your changes into the main branch.
6. Review and test changes before merging.

The team leader coordinates integration, reviews pull requests, and helps maintain consistency across the project.
